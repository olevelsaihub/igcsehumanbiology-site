Cells and tissues

Key facts

Locate DNA and chromosomes in a human cell

DNA is coiled into chromosomes, and the chromosomes are kept in the nucleus. Answer at the level the question asks: place, structure or molecule.

Key words: nucleus, chromosome, DNA, deoxyribose

Open this question type →

Compare light and electron microscopes and use their parts

An electron microscope has higher magnification and higher resolution, so more small structures show in detail. Link each microscope part to its action.

Key words: magnification, resolution, ribosomes, fine adjustment

Open this question type →

Draw or label a human cell as seen under the microscope

A human cell has a cell membrane, cytoplasm and a nucleus, but no cell wall. A cheek cell is flat with an uneven outline.

Key words: cell membrane, cytoplasm, nucleus, cilia

Open this question type →

Name the parts of a nucleotide and the DNA backbone

A DNA nucleotide has a phosphate, a deoxyribose sugar and a base. Sugar and phosphate alternate to make the backbone; the bases point inwards.

Key words: nucleotide, deoxyribose, phosphate, base

Open this question type →

Define a gene mutation and name its causes

A mutation is a change in the sequence of bases in DNA. Mutagens such as ultraviolet light and X-rays raise the rate of mutation.

Key words: mutation, substitution, mutagen, ionising radiation, uncontrolled division

Open this question type →

Define specialised cells, tissues and organs and identify human tissues

A tissue is a group of similar cells doing one job. An organ is made of several different tissues working together.

Key words: tissue, organ, squamous epithelium, ciliated epithelium, cardiac muscle

Open this question type →

Match human cell structures to their functions

Every cell structure has one main job. A mark needs the right name and an action verb for its job: controls, releases, makes, transports.

Key words: releases energy, genetic information, controls, protein synthesis, transports

Open this question type →

Relate sperm structures to their roles in fertilisation

Each sperm part links to fertilisation: the acrosome releases enzymes, the mid-piece releases energy for the tail, and the nucleus fuses with the egg.

Key words: acrosome, jelly coat, respiration, haploid, fertilisation

Open this question type →

Sequence and describe the stages of mitosis

The order is prophase, metaphase, anaphase, telophase (PMAT). For each stage, say what the chromosomes do.

Key words: prophase, metaphase, chromatids, poles, nuclear membrane

Open this question type →

Compare DNA with RNA

DNA has two strands, deoxyribose and thymine. RNA has one strand, ribose and uracil. Write each difference with both sides.

Key words: uracil, ribose, single-stranded, mRNA

Open this question type →

Describe DNA's double helix, base pairing and replication

DNA is a double helix of two strands joined by hydrogen bonds: A with T, C with G. In replication, free nucleotides pair with each old strand.

Key words: double helix, complementary, hydrogen bonds, DNA polymerase, thymine

Open this question type →

Describe genetic modification and gene therapy for human health

Genetic modification moves a gene, not the protein. A restriction enzyme cuts it out, ligase joins it into a plasmid, and the host makes the protein.

Key words: restriction enzyme, plasmid, DNA ligase, recombinant DNA, vector

Open this question type →

Describe the products and purposes of mitosis

Mitosis makes two daughter cells that are genetically identical to the parent and diploid. It is used for growth and repair.

Key words: daughter cells, genetically identical, diploid, growth, repair

Open this question type →

Describe transcription and translation in human cells

Transcription in the nucleus copies a gene into mRNA. Translation at a ribosome joins amino acids in the order the codons set.

Key words: transcription, codon, anticodon, peptide bonds, polypeptide

Open this question type →

Explain and evaluate uses of embryonic and adult stem cells

Stem cells are unspecialised and can differentiate. Embryonic cells become almost any cell but destroy an embryo; adult cells are fewer and limited.

Key words: differentiate, unspecialised, rejected, tumours, replace damaged cells

Open this question type →

Explain how a mutation changes a protein and phenotype

Explain a mutation as a chain: base sequence, then amino acids, then protein shape, then phenotype. Do not jump from DNA to the disease.

Key words: base sequence, codons, shape, active site, phenotype

Open this question type →

Apply the triplet code to bases, codons and amino acids

Three bases code for one amino acid. Convert one base at a time (U in RNA, not T), then read in threes.

Key words: triplet, codon, anticodon, uracil

Open this question type →

Biological molecules

Key facts

Recall the elements and building blocks of food molecules

Carbohydrates and lipids contain only C, H, O. Proteins also contain N. Proteins are made of amino acids, lipids of fatty acids and glycerol.

Key words: amino acids, fatty acids, nitrogen, disaccharide

Open this question type →

Make alginate beads and give uses and advantages of immobilised enzymes

An immobilised enzyme is trapped in alginate beads. It can be reused and does not contaminate the product.

Key words: immobilised, calcium chloride, reused, lactase, stable

Open this question type →

Name the food-test reagent or read food-test results

Each food test has its own reagent and its own colour change. Read every colour as present or absent, including the negative result.

Key words: Benedict's solution, iodine, biuret, negative result, water bath

Open this question type →

Describe how to carry out a food test, including DCPIP for vitamin C

Name the reagent, the key action and the colour change. Benedict's needs heat, iodine turns blue-black, biuret turns lilac, and DCPIP is decolourised by vitamin C.

Key words: biuret, Benedict's, iodine, ethanol, DCPIP

Open this question type →

Explain how enzymes work in biosensors and test strips

A biosensor has a membrane that lets glucose through and an immobilised enzyme that makes a product. The sensor detects the product, so more glucose gives a bigger reading.

Key words: partially permeable membrane, immobilised enzyme, glucose oxidase, electrode, reading

Open this question type →

Explain how inhibitors or a mutation change enzyme activity

A competitive inhibitor blocks the active site. A non-competitive inhibitor or a mutation changes its shape. Either way, fewer enzyme-substrate complexes form.

Key words: active site, competitive inhibitor, non-competitive inhibitor, enzyme-substrate complex, mutation

Open this question type →

Explain how temperature or pH changes enzyme activity

Warming gives more kinetic energy, so more collisions and a faster rate. Too hot, or the wrong pH, denatures the enzyme by changing its active site.

Key words: kinetic energy, collisions, denatured, active site, optimum

Open this question type →

Read an enzyme optimum from data and judge how reliable it is

The optimum is where the enzyme works fastest: the highest rate, or the shortest time. Gaps between values and no repeats make it uncertain.

Key words: optimum, shortest time, smaller intervals, repeats, valid

Open this question type →

Movement of substances into and out of cells

Key facts

Define diffusion, osmosis and active transport

Diffusion is movement down a concentration gradient. Osmosis is movement of water across a partially permeable membrane. Active transport goes against the gradient using ATP.

Key words: concentration gradient, partially permeable, water potential, ATP, carrier proteins

Open this question type →

Explain diffusion in a context and factors affecting its rate

Diffusion goes from high to low concentration. A steeper gradient, larger surface area or shorter distance means faster diffusion, because more particles cross each second.

Key words: concentration gradient, surface area, diffusion distance, kinetic energy

Open this question type →

Explain water movement by osmosis in body contexts

Water moves by osmosis from higher to lower water potential across a partially permeable membrane. More solute means a lower water potential.

Key words: water potential, partially permeable, solute, shrink

Open this question type →

Bones, muscles and joints

Key facts

Identify bones and bone tissues on a diagram

Use position to name bones: the humerus is the one upper-arm bone, and the radius is on the thumb side. A long bone has compact bone, spongy bone and cartilage.

Key words: humerus, radius, femur, compact bone, cartilage

Open this question type →

Name joint types and compare their movement

A joint is where two bones meet. The elbow and knee are hinge joints (one plane). The shoulder and hip are ball and socket joints (three planes and rotation).

Key words: joint, hinge joint, ball and socket joint, plane, rotate

Open this question type →

Draw or label the parts of a synovial joint

A synovial joint has cartilage on both bone ends, synovial fluid in the gap, a synovial membrane lining it and a capsule with ligaments outside.

Key words: cartilage, synovial fluid, synovial membrane, capsule, ligament

Open this question type →

State the function of a skeletal or joint part and explain effects of damage

Ligaments join bone to bone, tendons join muscle to bone, cartilage reduces friction and synovial fluid lubricates. Without cartilage, bones rub and the joint is painful.

Key words: ligament, tendon, cartilage, synovial fluid, friction

Open this question type →

Explain dietary needs for bone and muscle and describe osteoporosis

Calcium makes bone hard, vitamin D helps the gut absorb it and protein builds muscle. In osteoporosis bones lose density and break easily.

Key words: calcium, vitamin D, protein, osteoporosis, fracture

Open this question type →

Explain how biceps, triceps and tendons move the arm

Muscles can only pull. The biceps and triceps are an antagonistic pair: when one contracts, the other relaxes.

Key words: antagonistic pair, contracts, relaxes, tendon, hinge joint

Open this question type →

Coordination

Key facts

Name receptors and the senses or stimuli they detect

A receptor detects a stimulus and starts an impulse. Name the receptor or sense exactly, not the whole organ.

Key words: receptor, stimulus, rods, cones, wavelengths

Open this question type →

Define a reflex and name the neurones on the receptor-to-effector path

A reflex is fast, automatic and protective. The path is receptor, sensory, relay, motor neurone, effector.

Key words: reflex action, sensory neurone, relay neurone, motor neurone, effector

Open this question type →

Identify brain regions and match them to their functions

Each brain part has one key job: cerebrum for thought, cerebellum for balance, medulla for heart and breathing, hypothalamus for temperature.

Key words: cerebral hemispheres, cerebellum, medulla, hypothalamus, pituitary gland

Open this question type →

Identify parts of the eye and state their functions

Follow the light path: cornea, pupil, lens, retina, optic nerve. The cornea and lens focus light; the iris controls the amount.

Key words: refracts, retina, iris, optic nerve, choroid

Open this question type →

Match hormones to glands and effects, and contrast them with nerves

Hormones are chemical messages carried in the blood, so they are slower than nerve impulses. Learn each gland with its hormone and effect.

Key words: endocrine, insulin, ADH, thyroxine, adrenaline

Open this question type →

Draw, label and compare the structure of a neurone

A motor neurone has a cell body with a nucleus and dendrites, a very long axon, and a myelin sheath that insulates the axon and speeds impulses.

Key words: cell body, dendrites, axon, myelin sheath, synaptic knob

Open this question type →

State causes and symptoms of dementia, Parkinson's and mental illness

Each condition has its own symptoms. Give separate ideas, and never repeat a symptom the question rules out, such as memory loss.

Key words: beta-amyloid, tremor, hallucinations, short-term memory, risk factor

Open this question type →

Identify ear parts and use the sound path to explain hearing and hearing loss

Follow the sound path: pinna, eardrum, ossicles, cochlea, auditory nerve, brain. Hearing loss is a blocked or damaged step.

Key words: ossicles, cochlea, auditory nerve, Eustachian tube, semicircular canals

Open this question type →

Describe how an impulse crosses a synapse

At a synapse, vesicles release neurotransmitter, which diffuses across the gap and binds to receptors. This starts a new impulse.

Key words: synaptic knob, neurotransmitter, diffuses, receptors, exocytosis

Open this question type →

Explain eye defects and how they are corrected or treated

Short sight: distant objects blurred, rays meet in front of the retina, concave lens. Long sight: near objects blurred, rays meet behind, convex lens.

Key words: short sight, concave, convex, cataract, corneal transplant

Open this question type →

Explain how the eye focuses on near and distant objects

Accommodation changes the lens shape. Near: ciliary muscles contract, lens thicker. Distant: they relax, lens thinner.

Key words: accommodation, ciliary muscles, suspensory ligaments, convex, refracted

Open this question type →

Explain how the pupil responds to changes in light intensity

The iris muscles change the pupil size to control the light entering. Dim light: radial contract, pupil wider. Bright light: circular contract, pupil narrower.

Key words: radial muscles, circular muscles, dilates, constricts, reflex

Open this question type →

Explain stereoscopic vision and how it helps judge distance

Stereoscopic vision uses two forward-facing eyes. Each sees a slightly different view, and the brain combines them into a 3D image to judge distance.

Key words: stereoscopic, different angle, 3D, judge distance, repeat

Open this question type →

Explain the effects and dangers of alcohol and other drugs

Alcohol is a depressant: it slows the nervous system, so reaction time rises. Long-term heavy drinking damages the liver.

Key words: depressant, reaction time, absorbed, cirrhosis, stimulant

Open this question type →

Show and explain why impulses travel one way across a synapse

At a synapse, neurotransmitter is released only from the first neurone and diffuses across. Receptors are only on the next neurone, so impulses go one way.

Key words: synapse, neurotransmitter, vesicles, diffuses, receptors

Open this question type →

Show how an image forms on the retina and reaches the brain

Light is refracted at the cornea and again at the lens, so the rays cross and form an upside-down image on the retina. The optic nerve carries impulses to the brain.

Key words: refracted, inverted, retina, impulses, optic nerve

Open this question type →

Predict how a drug, toxin or disease changes synaptic transmission

A drug or disease changes one step of the synapse: release, diffusion, binding or breakdown. Say what that does to the impulses.

Key words: neurotransmitter, receptors, acetylcholinesterase, compete, depressant

Open this question type →

Nutrition and energy

Formulas

Calculate BMI and place it in a weight category

BMI = mass ÷ height²

mass = body mass (kg)

height = height (m)

  • Height × 2 is not height squared.
  • Mass ÷ height², never the other way up.

Key facts

Match digestive enzymes to substrate, product and site

Match enzyme, substrate and product: amylase, starch, maltose; protease, protein, amino acids; lipase, lipids, fatty acids and glycerol.

Key words: amylase, protease, lipase, fatty acids and glycerol, active site

Open this question type →

Explain how food moves by peristalsis and why fibre helps

Food is pushed along as a bolus by peristalsis: circular muscles contract behind it and relax in front. Fibre adds bulk to keep it moving.

Key words: bolus, peristalsis, circular muscles, bulk, constipation

Open this question type →

Identify alimentary canal organs and describe what each does

Food passes through the gut in order: mouth, oesophagus, stomach, small intestine, large intestine, anus. The liver and pancreas join by ducts.

Key words: oesophagus, amylase, pancreas, villi, absorbs water

Open this question type →

Link a nutrient to its function, source and deficiency disease

Link each nutrient to its job and to the deficiency disease its lack causes. Deficiency diseases are not infectious.

Key words: deficiency, scurvy, anaemia, kwashiorkor, connective tissue

Open this question type →

Name tooth types and tissues, state their jobs and compare tooth sets

Each tooth has layers from outside in: enamel, dentine, pulp cavity. Each tooth type has one job: cut, tear or grind.

Key words: enamel, dentine, pulp cavity, premolars, grind

Open this question type →

Explain causes of obesity, its health risks and dietary advice

Obesity happens when energy in is more than energy used over time; the extra is stored as fat. It raises the risk of several diseases.

Key words: stored as fat, energy balance, type 2 diabetes, arthritis, balanced diet

Open this question type →

Calculate BMI and place it in a weight category

BMI = mass in kg ÷ (height in m)². Square the height first, then use the paper's table to name the weight category.

Key words: BMI, squared, one decimal place, obese

Open this question type →

Define a balanced diet and explain why needs differ between people

A balanced diet has all the food components in the right proportions. Needs differ with sex, pregnancy, age and activity, and each needs a biological reason.

Key words: balanced diet, proportions, muscle mass, haemoglobin, fetus

Open this question type →

Explain how tooth decay happens and justify ways to prevent it

Bacteria in plaque respire sugar and release acid, which dissolves the enamel. Prevent decay by cutting sugar and strengthening enamel.

Key words: plaque, respire, lactic acid, enamel, fluoride

Open this question type →

Explain an enzyme practical result, including levelling off as substrate runs out

Name the enzyme, its substrate and its product, then link the product to what you saw. A reaction levels off when the substrate is used up.

Key words: lipase, amylase, fatty acids, substrate used up, limiting factor

Open this question type →

Explain how villi aid absorption and the effect of damage

A villus is built for absorption: large surface area, wall one cell thick, capillaries that keep a steep gradient, and a lacteal for fat.

Key words: villi, microvilli, surface area, concentration gradient, lacteal

Open this question type →

Explain where bile comes from and how it aids fat digestion

Bile is made in the liver and stored in the gall bladder. It emulsifies fat for a larger surface area and is alkaline, so it neutralises stomach acid.

Key words: emulsifies, surface area, lipase, alkaline, neutralises

Open this question type →

Apply digestive enzyme action to an unfamiliar situation

In an unfamiliar situation, name the molecule, the enzyme and the product. Then say what happens to absorption.

Key words: protease, lactase, absorbed, lipase, digested

Open this question type →

Respiration

Key facts

Write or complete the respiration equations

Aerobic respiration: glucose + oxygen → carbon dioxide + water, releasing energy. Anaerobic respiration in muscle makes lactic acid and no carbon dioxide.

Key words: glucose, oxygen, carbon dioxide, lactic acid, ATP

Open this question type →

Explain how respiration releases energy and ATP transfers it

Respiration releases energy from glucose. That energy joins a phosphate to ADP to make ATP. Breaking ATP down releases energy for the cell.

Key words: respiration, ATP, ADP, phosphate, metabolic rate

Open this question type →

Set up and explain the indicator practical comparing carbon dioxide in breath

Expired air has about 4% carbon dioxide, inspired air about 0.04%. Limewater goes cloudy faster with expired air because cells make carbon dioxide in respiration.

Key words: limewater, expired air, respiration, fresh, same number of breaths

Open this question type →

Gas exchange

Formulas

Calculate breathing rate or air volume from trace or table

Air per minute = tidal volume × breaths per minute

tidal volume = volume of one breath (cm³)

breaths per minute = breathing rate (per min)

  • Scale a 30 s count up to 60 s.
  • 1 dm³ = 1000 cm³: divide cm³ by 1000.

Key facts

Name thorax and airway structures and the route of air

Air passes through the trachea, two bronchi, many bronchioles and into the alveoli. Name each part by its level of branching.

Key words: trachea, bronchi, bronchioles, alveoli, intercostal muscles

Open this question type →

Explain how airway features keep air clean and flowing

Mucus traps dust and pathogens; cilia sweep it away; cartilage rings keep the airways open. Smoke damages cilia, so infection risk rises.

Key words: mucus, cilia, goblet cells, cartilage, paralysed

Open this question type →

Calculate breathing rate or air volume from trace or table

Air per minute = tidal volume × breaths per minute. Count peaks only, and convert the units at the end.

Key words: tidal volume, breaths per minute, peak, 20%, divide by 1000

Open this question type →

Explain how diaphragm and intercostal muscles drive breathing

To breathe in, the intercostal muscles and diaphragm contract. The volume of the thorax rises, the pressure falls, and air is drawn in.

Key words: contract, flattens, up and out, volume, pressure

Open this question type →

Explain how smoking damages health, including in pregnancy

Tar causes cancer and damages cilia; carbon monoxide reduces oxygen carried; nicotine is addictive and narrows vessels. Less oxygen harms a fetus.

Key words: carcinogenic, carbon monoxide, carboxyhaemoglobin, nicotine, birth mass

Open this question type →

Use a spirometer and identify lung volumes on its trace

A spirometer trace shows tidal volume in small waves, vital capacity in the biggest wave and residual volume below the lowest point.

Key words: tidal volume, vital capacity, residual volume, nose clip, soda lime

Open this question type →

Explain heart and breathing changes in exercise and how carbon dioxide controls breathing

Exercise raises the need for oxygen and glucose, so the heart rate rises. Rising carbon dioxide is detected and the medulla oblongata raises breathing.

Key words: chemoreceptors, medulla oblongata, aerobic respiration, lactic acid, oxygen debt

Open this question type →

Explain how alveoli are adapted for gas exchange and effects of damage

Alveoli have a large surface area, thin walls and many capillaries for fast diffusion. In emphysema the walls break down, so less oxygen reaches the blood.

Key words: surface area, diffusion distance, concentration gradient, emphysema, aerobic respiration

Open this question type →

Internal transport

Key facts

Identify blood components and match them to their features and jobs

Blood has four parts: red cells (haemoglobin, no nucleus), white cells (a nucleus), platelets (cell fragments) and plasma (the liquid).

Key words: haemoglobin, phagocyte, lymphocyte, platelets, plasma

Open this question type →

Describe phagocytosis, antibody production and barriers to pathogens

A phagocyte engulfs a pathogen in a vacuole, and lysosome enzymes digest it. Lymphocytes make antibodies; skin and mucus are barriers.

Key words: phagocytosis, vacuole, lysosome, digestive enzymes, antibodies

Open this question type →

Name heart chambers and major vessels from a diagram

Arteries leave the ventricles; veins enter the atria. On a front view, the heart's left side is on your right.

Key words: vena cava, pulmonary artery, pulmonary vein, aorta, oxygenated

Open this question type →

Describe what red cells and plasma carry, and from where to where

Red cells carry oxygen on haemoglobin. Plasma carries dissolved substances such as glucose, urea, hormones and heat. Always give a destination.

Key words: haemoglobin, plasma, urea, hormones, absorbed

Open this question type →

Trace the route of blood through the heart, lungs and body

The heart is a double pump: the right side sends blood to the lungs, the left side to the body. Blood passes through the heart twice in one circuit.

Key words: double pump, deoxygenated, oxygenated, twice, away from the heart

Open this question type →

Describe how blood clots and explain why clotting matters

At a wound platelets release an enzyme, prothrombin becomes thrombin, and soluble fibrinogen becomes insoluble fibrin. The fibrin mesh traps cells to form a clot.

Key words: platelets, prothrombin, thrombin, fibrinogen, fibrin

Open this question type →

Describe how heart disease is prevented and treated

Prevent heart disease with specific lifestyle changes or statins. Treat a blocked artery with a stent or bypass that restores blood and oxygen to the muscle.

Key words: saturated fat, statins, stent, bypass, rejected

Open this question type →

Explain chamber wall thickness and heart valves by their function

A thicker wall has more muscle, so it contracts more strongly and gives a higher pressure. Valves stop backflow, so blood goes one way.

Key words: more muscle, high pressure, aorta, valve, backflow

Open this question type →

Explain how a blocked coronary artery damages the heart

A blocked coronary artery means less blood, so less oxygen and glucose reach the heart muscle. Less aerobic respiration releases less energy, and the muscle can die.

Key words: coronary artery, fatty deposit, aerobic respiration, releases less energy, heart attack

Open this question type →

Identify arteries, veins and capillaries and relate their structure to function

Arteries have thick, elastic walls for high pressure; veins have a wide lumen and valves; capillaries have walls one cell thick for exchange.

Key words: lumen, valves, elastic, diffusion distance, high pressure

Open this question type →

Interpret a raised or lowered blood cell count

Compare with the healthy value. A high white cell count usually means infection; a low platelet count means slow clotting and longer bleeding.

Key words: white cell count, phagocytes, antibodies, platelet count, healthy value

Open this question type →

Explain red-cell adaptations and the effects of more or less oxygen carriage

A red cell is built to carry oxygen: haemoglobin, no nucleus, a biconcave shape. Less oxygen carried means less aerobic respiration and less energy released.

Key words: haemoglobin, oxyhaemoglobin, biconcave, aerobic respiration, deoxygenated

Open this question type →

Explain systolic, diastolic and changing pressure around the circulation

Systolic pressure is the peak when the ventricles contract; diastolic is the low when they relax. Blood always flows from high to low pressure.

Key words: systolic, diastolic, contracts, higher to lower pressure, elastic tissue

Open this question type →

Use ABO antigens and antibodies to choose donors and explain clumping

Red cells carry antigens; plasma holds antibodies. If donor antigens meet matching antibodies the cells clump (agglutination), which can block vessels.

Key words: antigen, antibodies, agglutination, group O, recipient

Open this question type →

Explain how beta-blockers and ACE inhibitors lower heart rate or pressure

Beta-blockers block receptors on heart muscle, so heart rate and pressure fall. ACE inhibitors stop the enzyme ACE, so vessels widen.

Key words: receptors, adrenaline, heart rate, enzyme, angiotensin II

Open this question type →

Explain how tissue fluid forms, what it does and why it builds up

At the arteriole end of a capillary, high pressure forces water and small molecules out through gaps, making tissue fluid. Cells and large proteins stay in.

Key words: tissue fluid, high pressure, pores, too large, lymph vessels

Open this question type →

Homeostatic mechanisms

Key facts

Identify skin structures and state what each does

The skin has three layers: epidermis, dermis and a fat layer. Give each structure a specific job, such as "insulates, reducing heat loss".

Key words: epidermis, insulates, ultraviolet light, sweat gland, pathogens

Open this question type →

Identify urinary system and nephron structures

Follow the path: renal artery, glomerulus in the Bowman's capsule, proximal tubule, loop of Henle, distal tubule, collecting duct, ureter, bladder, urethra.

Key words: glomerulus, Bowman's capsule, loop of Henle, collecting duct, ureter

Open this question type →

Compare blood entering and leaving the kidney

Compared with the renal artery, blood in the renal vein has less urea, less oxygen and more carbon dioxide. Always say which vessel has more or less.

Key words: renal vein, less urea, respiration, excreted, carbon dioxide

Open this question type →

Evaluate kidney transplants and dialysis as treatments

A transplant is a long-term fix but risks rejection. Dialysis is available to all but is only temporary. A good answer gives both sides of each.

Key words: rejected, immunosuppressant, shortage of donors, temporary, diet

Open this question type →

Explain homeostasis and negative feedback

Homeostasis keeps the internal environment constant. In negative feedback a change is detected and a response reverses it, then switches off.

Key words: homeostasis, internal environment, negative feedback, denatured, optimum

Open this question type →

Explain how ADH changes urine volume and concentration

The hypothalamus detects blood water; the pituitary releases ADH. ADH makes the collecting ducts more permeable, so more water is reabsorbed into the blood.

Key words: hypothalamus, pituitary gland, permeable, reabsorbed, concentrated

Open this question type →

Explain how insulin and glucagon control blood glucose

The pancreas detects blood glucose. Insulin makes the liver and muscles store it as glycogen; glucagon makes the liver turn glycogen back into glucose.

Key words: pancreas, insulin, glucagon, glycogen, glucose

Open this question type →

Explain how skin blood flow and sweating control body temperature

The hypothalamus detects blood temperature. When hot, skin arterioles widen and sweat evaporates; when cold, they narrow and muscles shiver.

Key words: hypothalamus, vasodilation, vasoconstriction, evaporates, radiation

Open this question type →

Explain the liver's roles in deamination and breaking down drugs

Extra amino acids cannot be stored, so the liver deaminates them and makes urea for the kidneys to excrete. The liver also breaks down drugs and alcohol.

Key words: deamination, urea, excreted, cannot be stored, detoxification

Open this question type →

Explain diffusion across a partially permeable membrane in dialysis and Visking tubing

Small molecules diffuse through a partially permeable membrane down a concentration gradient; large ones cannot pass. Dialysis fluid has no urea.

Key words: partially permeable, concentration gradient, diffuses, too large, same concentration

Open this question type →

Explain ultrafiltration and selective reabsorption in the nephron

In the glomerulus, high pressure forces small molecules out of the blood by ultrafiltration. In the proximal tubule, all the glucose is reabsorbed.

Key words: ultrafiltration, high pressure, too large, selective reabsorption, proximal convoluted tubule

Open this question type →

Judge whether data support a claim and spot their limits

To judge a claim, quote a figure from the data, then say what the data cannot show. A correlation does not prove cause.

Key words: correlation, anomalous, small sample, other factors, supports

Open this question type →

Reproduction and heredity

Key facts

State the role of a named reproductive hormone

Give one clear action for each hormone: FSH matures follicles, LH triggers ovulation, oestrogen repairs the lining, progesterone maintains it.

Key words: matures, triggers ovulation, repairs, maintains, corpus luteum

Open this question type →

Identify reproductive organs from their roles or positions

Match each job to its organ: sperm are made in the testes, fertilisation is in the oviduct, and the urethra carries urine and semen.

Key words: testes, epididymis, urethra, oviduct, implants

Open this question type →

Describe labour and the advantages of breastfeeding

Oxytocin makes the uterus muscles contract in labour, widening the cervix and pushing the baby out. Breast milk gives the baby antibodies.

Key words: oxytocin, contract, dilates, antibodies, bonding

Open this question type →

Describe the steps of IVF treatment

In IVF, eggs are fertilised outside the body in a dish. Give the steps in order, starting with FSH and LH and ending with embryos placed in the uterus.

Key words: in-vitro, FSH, laboratory, embryo, implant

Open this question type →

State the symptoms and effects of inherited conditions

Name the main effect first, then the organ and its consequence. Cystic fibrosis makes thick, sticky mucus; haemophilia stops blood clotting.

Key words: clot, thick, sticky mucus, gas exchange, absorbed, infertile

Open this question type →

Maths skills

Formulas

Convert units and write numbers in standard form or significant figures

A × 10^n, where 1 ≤ A < 10

A = number from 1 to under 10 (none)

n = places the point moved (none)

  • Large number: positive n. Small number: negative n.
  • Keep the size when rounding: use zeros.

Express a part as a percentage of a total

% = part ÷ whole × 100

part = the group asked about (number)

whole = total of that group (number)

  • Part on top, whole on the bottom.
  • The answer must be below 100%.

Find a mean, median, mode or mean rate of change

mean = total ÷ number of values

total = sum of the values (same unit)

number = how many values (none)

  • Divide by how many values there are.
  • A mean rate divides the change by the time.

Calculate and express a ratio in a required form

1 : n, where n = second ÷ first

first = value named first (same unit)

second = value named second (same unit)

  • Keep the order the question gives.
  • The ratio needs a colon and a 1.

Calculate area, volume and surface area to volume ratio

SA : V = 6 × side² : side³

side = cube side (mm)

SA = surface area (mm2)

V = volume (mm3)

  • 6 faces, not 4 or 1.
  • Volume is side × side × side.

Calculate a percentage change or percentage difference

% change = (new - original) ÷ original × 100

new = later value (same unit)

original = starting value (same unit)

  • Divide by the original, never the new value.
  • Subtract first: new minus original.

Calculate an amount from a percentage, fraction or probability

amount = total × percentage ÷ 100

total = whole amount (number or unit)

percentage = share wanted (%)

  • Multiply the total, do not divide by the percentage.
  • For a rise or fall, give the new value.

Scale a rate per 100 000 people to a whole population

cases = rate × population ÷ 100 000

rate = cases per 100 000 (number)

population = people in the group (number)

  • Divide the population first, then multiply.
  • Use the base the rate gives.

Scale per-unit or reference quantities and combine them

amount = amount per 100 g ÷ 100 × mass

per 100 g = label value (g)

mass = new mass (g)

  • Divide by 100, then multiply by the mass.
  • Keep g with g and mg with mg.

Use image size, actual size and magnification

magnification = image size ÷ actual size

image = size in the picture (mm)

actual = real size (mm)

  • Image on top, actual on the bottom.
  • Convert to the same unit first.

Substitute into a given equation, rearranging and converting units

time = distance ÷ speed

distance = how far (mm)

speed = rate of movement (mm/s)

time = time taken (s)

  • Divide distance by speed.
  • Convert seconds to minutes at the end.
