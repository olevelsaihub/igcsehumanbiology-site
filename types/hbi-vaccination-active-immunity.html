Explain how vaccination or infection gives active immunity

How vaccines or a first infection lead to antibodies and memory cells, why boosters are given, and herd protection.

Long ordered chains, plus graph-based reasoning for boosters and population effects. Memory cells and the secondary response are abstract. Antibody graphs are read qualitatively, with no calculation. The method

  1. What enters

    Antigens in a dead or weakened pathogen.

  2. Antibodies

    Lymphocytes make specific antibodies.

  3. Memory cells

    They are formed and stay in the body.

  4. Re-infection

    Memory cells make antibodies faster and in larger amounts.

  5. Boosters and population

    Boosters raise antibody level; fewer carriers means less spread.

Do not lose marks here

  • ✗
    Vaccine has antibodies

    It has antigens; you make the antibodies.

  • ✗
    "Body remembers"

    Name memory cells.

  • ✗
    Antibodies last for life

    Levels fall; memory cells stay.

Worked explanation

  1. 'Explain how vaccination can give a person immunity', 5 marks: five steps in order.
  2. What is injected? A weakened or dead form of the pathogen, which carries antigens.
  3. What does the body do? Lymphocytes produce antibodies against it.
  4. What stays afterwards? Some antibodies stay in the blood for a time, and memory cells are made.
  5. What happens later? On a real infection, memory cells make antibodies very fast, so the person does not become ill.
  6. Count: injected pathogen, antibodies made, antibodies stay, memory cells, fast response. Five.
Model answer · written by olevels.com, not an official Pearson mark scheme

A vaccine containing a dead or weakened (attenuated) form of the pathogen is injected. Its antigens are detected by lymphocytes, which then make antibodies against them. Some of these antibodies stay in the blood for a while. Lymphocytes also form memory cells, which remain in the body for a long time. If the real pathogen enters later, the memory cells quickly make large amounts of antibodies, so the pathogen is destroyed before the person becomes ill.

How the marks are earned

One mark each for: a weakened or attenuated pathogen being injected; antibodies being produced; antibodies staying in the blood; memory cells forming; a quick antibody response when infection happens later.
