Apply the triplet code to bases, codons and amino acids

Converting DNA triplets to mRNA codons and tRNA anticodons, reading amino acids from a table, counting bases per amino acid, and counting possible codes as a power.

Type 17 Cells and tissues HBI-APPLY-TRIPLET-CODE

★★☆☆☆ · 4 of 36 eligible examination papers, 2019–2025. Difficulty: Difficult.

Several conversion steps or a two-step calculation. Needs codon, anticodon and template-strand ideas held together. Multiplying, dividing by 3 and using a power of 4. Tables differ between papers in which strand they list. Links base pairing, protein synthesis and mutation.

The method

  1. Start and end

    Which molecule do you have, and which do you need?

  2. Convert

    One base at a time, U in RNA.

  3. Read in threes

    Start from the first base.

  4. Count

    Multiply or divide by 3, and show it.

Do not lose marks here

  • ✗
    T in RNA

    Use U.

  • ✗
    Unconverted lookup

    Convert an mRNA codon before using a DNA table.

  • ✗
    Doubling for strands

    One strand only.

  • ✗
    4 × 3

    Write 4³ = 64.

Worked explanation

  1. Amino acid X is attached to a tRNA. The tRNA anticodon in the diagram is UGU.
  2. The anticodon pairs with the mRNA codon. U pairs with A, G pairs with C, U pairs with A, so the codon is ACA.
  3. The table lists DNA triplets, so I need the DNA triplet that made the codon ACA. A on mRNA came from T on DNA, C came from G, A came from T. So the DNA triplet is TGT.
  4. Shortcut check: the anticodon UGU is the DNA triplet with U in place of T, which gives TGT again.
  5. In the table, TGT codes for threonine.
Model answer · written by olevels.com, not an official Pearson mark scheme

threonine

How the marks are earned

One mark for threonine. Students who look up the codon ACA directly in the DNA table get cysteine, which is wrong.
