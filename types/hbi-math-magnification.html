Human Biology / Use image size, actual size and magnification

Pearson Edexcel · International GCSE Human Biology · 4HB1

Use image size, actual size and magnification

A micrograph or diagram with a measurable length, a stated real size or magnification, or eyepiece and objective lenses.

Type 19 Maths skills HBI-MATH-MAGNIFICATION

★★★★★ · 12 of 36 eligible examination papers, 2019–2025. Difficulty: Difficult.

Students must choose the right rearrangement and unit path. Image versus actual size is a clear idea. Unit conversions with powers of ten and small decimals. Different cells and units each time. Combines measuring, converting units and rearranging.

The method

  1. Measure

    Ruler in mm between the named points.

  2. Same unit

    Convert um and mm.

  3. Rearrange

    Magnification, actual or image as the subject.

  4. Calculate

    Give a × or the unit asked.

Do not lose marks here

  • ✗
    Actual ÷ image

    Image goes on top.

  • ✗
    Unit slip

    um to mm is a factor of 1000.

  • ✗
    Adding lenses

    Multiply eyepiece × objective.

After your attempt, see the full worked explanation

Worked explanation

  1. Image length = 84 mm. Actual length = 0.0060 mm. Both are already in mm.
  2. Magnification = image size / actual size.
  3. = 84 / 0.0060
  4. = 14 000
  5. Check: the image is far bigger than the real cell, so a large number makes sense.
Model answer · written by olevels.com, not an official Pearson mark scheme

Magnification = image size / actual size = 84 / 0.0060 = x 14 000

How the marks are earned

One mark for dividing the image length (84) by the actual length (0.006). One mark for the answer 14 000.

Calculation check

  • 84 ÷ 0.0060 = 14000.0
