Define a reflex and name the neurones on the receptor-to-effector path

Written

A reflex is fast, automatic and protective. The path is receptor, sensory, relay, motor neurone, effector.

Name each part along the path.

  2. Relay neurone
  3. Motor neurone
  4. Effector

Sensory neurone

Job
Carries impulses from the receptor to the CNS.

Relay neurone

Job
Links the sensory and motor neurones inside the CNS.

Motor neurone

Job
Carries impulses from the CNS to the effector.

Exam tipNot "messages to the brain".

Effector

Write it as
The effector is a muscle (or gland).

4

The method

  1. Find the ends

    Locate the receptor and the effector.

  2. Name in order

    Sensory, then relay, then motor.

  3. Jobs

    Say what each carries, from where to where.

  4. Define

    Fast, automatic and protective.

Do not lose marks here

  • ✗
    Wrong order

    The neurone touching the muscle is motor.

  • ✗
    Motor to brain

    Motor carries impulses away from the CNS.

  • ✗
    Only "quick"

    Give three ideas for three marks.

  • ✗
    Vague difference

    Say which neurone has which feature.

Worked explanation

  1. The question asks me to name neurones A, B and C in Diagram 1. It is worth 3 marks, so one mark per letter.
  2. I find the receptor end of the arc. Neurone C starts there and carries impulses into the spinal cord. So C is the sensory neurone.
  3. Neurone B is the short neurone in the middle, inside the spinal cord. It joins the other two neurones. So B is the relay neurone.
  4. Neurone A leaves the spinal cord and goes to the effector muscle. So A is the motor neurone.
  5. I check the order: receptor, C (sensory), B (relay), A (motor), muscle. The route makes sense.
Model answer · written by olevels.com, not an official Pearson mark scheme

A: motor neurone

B: relay neurone

C: sensory neurone

How the marks are earned

One mark for each correct name. A must be motor, B must be relay (connector or association neurone is also accepted), and C must be sensory. Swapping two names loses both of those marks.
