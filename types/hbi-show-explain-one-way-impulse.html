Show and explain why impulses travel one way across a synapse

Written

At a synapse, neurotransmitter is released only from the first neurone and diffuses across. Receptors are only on the next neurone, so impulses go one way.

Worked explanation

  1. The question asks why an impulse can only travel one way across a synapse. It is worth 4 marks, so I need four separate ideas.
  2. First idea: where the chemical comes from. The vesicles with neurotransmitter are only in the synaptic knob, so the chemical is released from that side only.
  3. Second idea: how it moves. It diffuses across the gap.
  4. Third idea: which way diffusion goes. It moves from high concentration near the knob to low concentration on the far side, so it only spreads one way.
  5. Fourth idea: where it acts. The receptors that the chemical binds to are only on the membrane of the next neurone.
  6. I write these in order as short sentences.
Model answer · written by olevels.com, not an official Pearson mark scheme

Neurotransmitter is stored in vesicles in the synaptic knob, so it can only be released from the first (pre-synaptic) neurone. It then diffuses across the gap in one direction, from where its concentration is high (next to the knob) to where it is low (next to the second neurone). The receptor molecules that the neurotransmitter binds to are found only on the post-synaptic membrane of the second neurone, so a new impulse can only start on that side.

How the marks are earned

One mark for saying the neurotransmitter comes out of one side only. One mark for saying it can only diffuse one way. One mark for the high-to-low concentration idea. One mark for saying receptors are only on the post-synaptic membrane. Saying 'the impulse jumps the gap' earns nothing.
