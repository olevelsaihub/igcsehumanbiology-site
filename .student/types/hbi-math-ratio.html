Calculate and express a ratio in a required form

Two values, counted, read from a graph or table, are compared as a ratio in simplest form, 1 : n, n : 1, or as how many times greater.

Type 8 Maths skills HBI-MATH-RATIO

★★★★★ · 11 of 36 eligible examination papers, 2019–2025. Difficulty: Medium.

Students must keep the named order and choose which side becomes 1. Ratio as a scaled comparison. One division and rounding. The 1 : n versus n : 1 forms confuse many students. Often needs a reading from a graph or table first.

5

The method

  1. Order

    Write the values in the order named.

  2. Units

    Check they match.

  3. Divide

    Make the required side 1.

  4. Write it

    Use a colon and round sensibly.

Do not lose marks here

  • ✗
    Wrong way round

    Healthy first if healthy is named first.

  • ✗
    Only one number

    Write 1 : 1.83, with a colon.

  • ✗
    Rough graph reading

    Write both readings down first.

Worked explanation

  1. The table columns are Healthy person, Person A, Person B.
  2. White blood cells: healthy person = 7500 per cm3; person A = 13 750 per cm3.
  3. The order asked is healthy : person A, so the ratio is 7500 : 13 750.
  4. For 1 : n, divide both sides by 7500: 1 : 13 750 / 7500.
  5. 13 750 / 7500 = 1.833..., so the ratio is 1 : 1.83.
Model answer · written by olevels.com, not an official Pearson mark scheme

Healthy : person A = 7500 : 13 750. 13 750 / 7500 = 1.83. Ratio = 1 : 1.83

How the marks are earned

One mark for dividing 13 750 by 7500. One mark for the ratio 1 : 1.83 (1 : 1.8 and 1 : 2 are also accepted).
