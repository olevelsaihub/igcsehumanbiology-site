Knowledge card

Apply the triplet code to bases, codons and amino acids

Written
  • Three bases in a row (a triplet) code for one amino acid. On mRNA a triplet is called a codon; on tRNA the matching triplet is an anticodon.
  • Base pairing rules: in DNA, A-T and C-G; between DNA and RNA, A on DNA pairs with U on RNA; between codon and anticodon, A-U and C-G.
  • A tRNA anticodon has the same bases as the DNA template triplet, except that U replaces T.
  • Number of bases (one strand) = number of amino acids × 3; number of amino acids = number of bases ÷ 3.
  • With 4 bases and 3 positions, the number of different triplets is 4 × 4 × 4 = 4³ = 64.
  • Deleting a whole triplet removes one amino acid from the protein; the protein can then have a different shape.

Before you begin

  • Complementary base pairing in DNA and RNA.
  • Transcription and translation.
  • Multiplying, dividing and using powers.
1

The method

  1. Write down which molecule you start with (DNA, mRNA or tRNA) and which one the table uses.

    Why: Tables can list DNA triplets; you must convert to the same molecule before you look up.

  2. Convert one base at a time using the pairing rules, remembering U in RNA instead of T.

    Why: One wrong pairing gives the wrong amino acid.

  3. Read bases in groups of three, from the start of the sequence.

    Why: Each group of three is one codon; reading out of step gives nonsense.

  4. For counts, multiply or divide by 3 and show the working.

    Why: The working line earns a mark even if the final number is wrong.

  5. For the number of possible codes, use 4 to the power 3.

    Why: The scheme credits the power expression and then the answer 64.

Do not lose marks here

  • ✗
    Using T in an RNA sequence, or U in a DNA sequence.
  • ✗
    Looking up an mRNA codon in a table of DNA triplets without converting it.
  • ✗
    Multiplying by 2 for two strands when the question asks for one strand.
  • ✗
    Writing 4 × 3 = 12 instead of 4³ = 64 for the number of codes.
  • ✗
    Reading the sequence in pairs or starting in the middle of a triplet.

Worked explanation

  1. Amino acid X is attached to a tRNA. The tRNA anticodon in the diagram is UGU.
  2. The anticodon pairs with the mRNA codon. U pairs with A, G pairs with C, U pairs with A, so the codon is ACA.
  3. The table lists DNA triplets, so I need the DNA triplet that made the codon ACA. A on mRNA came from T on DNA, C came from G, A came from T. So the DNA triplet is TGT.
  4. Shortcut check: the anticodon UGU is the DNA triplet with U in place of T, which gives TGT again.
  5. In the table, TGT codes for threonine.
Model answer · written by olevels.com, not an official Pearson mark scheme

threonine

How the marks are earned

One mark for threonine. Students who look up the codon ACA directly in the DNA table get cysteine, which is wrong.
