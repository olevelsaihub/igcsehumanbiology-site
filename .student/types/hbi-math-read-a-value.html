Knowledge card

Read or estimate a value from a graph, chart, table or image

Written
  • Find the value of one small square on each axis before reading.
  • Draw a ruler line from the axis to the curve or bar, then across to the other axis.
  • Read to the nearest half small square and include the unit.
  • A 'when' question wants an x-axis value (a time or year); a 'how much' question wants a y-axis value.
  • To estimate a proportion from a picture, measure the part and the whole and divide.
  • A threshold question (such as a legal limit) asks where the line crosses a given level.
  • For the greatest difference between two lines, find the x-value where the vertical gap between them is largest.
  • On a percentile chart, find the point for the age and mass, then name the percentile line it lies on.
  • If the image gives a known length (such as a layer 300 um thick), compare the unknown part with it to estimate its size.
  • For a total, read each value separately and then add them.

Before you begin

  • Reading axes and scales.
  • Measuring with a ruler.
  • Fractions, decimals and percentages.
1

The method

  1. Find which axis has the known value and which has the value you want.

    Why: Reading the wrong axis gives a meaningless answer.

  2. Work out the scale on the axis you will read.

    Why: Scale errors are the commonest cause of lost marks.

  3. Draw guide lines with a ruler from the known value to the line, then to the other axis.

    Why: This keeps the reading inside the tolerance.

  4. Read the value and add the unit.

    Why: The mark needs a value in range.

  5. For an image, measure the part and the whole in mm and divide.

    Why: Proportion answers are accepted as fraction, decimal or percentage.

Do not lose marks here

  • ✗
    Reading the y-value when the question asks 'how many hours' (an x-value).
  • ✗
    Taking the time where the curve peaks instead of where it falls below the limit.
  • ✗
    Counting each small square as 1 unit when it is worth more.
  • ✗
    Reading the wrong line on a graph with two lines.

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

How each command word is answered

Command wordTimes askedWhat to write
Determine5Give the value read from the graph; a guide line on the graph supports it.
Estimate4Give a sensible value in range; for images, a simple fraction such as one quarter is fine.
Complete1Read each bar or point and write the values in the table.
Compare1Give both readings and say which is higher, with the difference if possible.

Worked explanation

  1. The legal limit is 80 mg per 100 ml. That is a y-axis value.
  2. I draw a ruler line across from 80 on the y-axis to where it meets the falling part of the curve.
  3. Then I go down to the x-axis. Each hour has 10 small squares, so one small square is 0.1 hour.
  4. The curve falls below 80 at 2.4 hours.
  5. 0.4 hours = 0.4 x 60 = 24 minutes, so this is 2 hours 24 minutes. After this time it is legal to drive.
Model answer · written by olevels.com, not an official Pearson mark scheme

2.4 hours (2 hours 24 minutes) after drinking, or any time later than this.

How the marks are earned

One mark for a time of 2.4 hours (2 hours 24 minutes) or any time after it. A small range around this time is accepted.

Calculation check

  • 0.4 × 60 = 24.0
