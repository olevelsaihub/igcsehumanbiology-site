Knowledge card

Name the food-test reagent or read food-test results

Written
  • Benedict's solution tests for reducing sugar such as glucose; it needs a water bath. Brick red means sugar is present; blue means none.
  • Iodine solution tests for starch. Blue-black means starch; yellow-brown means none.
  • Biuret solution tests for protein. Purple or lilac means protein; blue means none.
  • Ethanol and water test for lipid. A milky emulsion means lipid.
  • DCPIP tests for vitamin C; it loses its blue colour.
  • Starch molecules are too large to pass through Visking tubing; glucose is small enough to pass.
  • Equipment for a Benedict's test: a water bath (or Bunsen burner) to heat the tube, and a measuring cylinder to measure the volumes.

Before you begin

  • The four food tests and their colours.
  • Visking tubing is partially permeable, like the gut wall.
1

The method

  1. For each test in the table, write down which nutrient it detects.

    Why: You cannot read a result until you know what the test is for.

  2. Turn each colour into 'present' or 'absent'.

    Why: Each correct reading is one mark.

  3. Combine the readings to match the question, for example 'protein but no starch'.

    Why: Questions often ask for two conditions at once; both must fit.

  4. When an unknown solution is labelled, use the colour it gave to name it (blue-black means iodine).

    Why: Naming a reagent from its result is a common one-mark item.

  5. When asked how many samples gave a positive result, count every positive colour exactly as recorded, even a control that looks odd.

    Why: The question asks what the results show, so count what is in the table.

Do not lose marks here

  • ✗
    Saying blue after Benedict's means sugar is present.
  • ✗
    Reading blue after biuret as a positive protein result.
  • ✗
    Only listing what is present and forgetting the nutrient shown to be absent.
  • ✗
    Naming 'iodine' for glucose or 'Benedict's' for starch.
  • ✗
    Giving one sample when the question asks for 'powders' (plural).

Common mistakes: Inferred, not measured. Inferred from the official schemes' credit and rejection patterns; not measured student-error statistics.

Worked explanation

  1. There are three tests on one food solution. I take them one at a time.
  2. Iodine gave blue-black. Iodine tests for starch, so starch is present.
  3. Biuret gave purple. Biuret tests for protein, so protein is present.
  4. Benedict's stayed blue. Benedict's tests for reducing sugar, and blue is a negative result, so there is no reducing sugar.
  5. There are 3 marks, so I write all three conclusions, including the one that is absent.
Model answer · written by olevels.com, not an official Pearson mark scheme

The food contains starch, because iodine turned blue-black. It contains protein, because biuret turned purple. It does not contain reducing sugar (glucose), because Benedict's solution stayed blue.

How the marks are earned

One mark for starch present, one for protein present and one for no reducing sugar. The negative result is the mark most often missed.
