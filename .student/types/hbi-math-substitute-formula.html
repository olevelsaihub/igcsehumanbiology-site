Worked explanation

  1. speed = distance / time, so time = distance / speed.
  2. Distance = 180 mm and speed = 0.070 mm/s. The units match (mm), so the time will be in seconds.
  3. time = 180 / 0.070 = 2571.4 s.
  4. The answer must be in minutes: 2571.4 / 60 = 42.86 minutes.
  5. Round sensibly: 43 minutes.
Model answer · written by olevels.com, not an official Pearson mark scheme

time = distance / speed = 180 / 0.070 = 2571 s. 2571 / 60 = 42.9 = 43 minutes.

How the marks are earned

One mark for dividing 180 by 0.070. One mark for 2571 seconds. One mark for dividing by 60 to give about 43 minutes (any value that rounds to 43). The last mark can follow on from a wrong seconds value if it is divided by 60 correctly.
