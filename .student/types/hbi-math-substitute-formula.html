Knowledge card

Substitute into a given equation, rearranging and converting units

Calculation
  • speed = distance / time, so time = distance / speed and distance = speed x time.
  • Change all values to matching units before you substitute (m with m/s, mm with mm/s).
  • Convert time units at the end if asked: seconds / 60 = minutes; seconds x 1000 = milliseconds.
  • Other given formulas include energy = mass x 4.2 x temperature rise, energy = force x distance, cardiac output = heart rate x stroke volume.
  • 1 dm3 = 1000 cm3.
  • Some formulas have a square root, e.g. reaction time = square root of (ruler distance in m / 5). Divide first, then take the square root: 0.15 m gives 0.17 s.
  • Many items chain steps, e.g. units in four glasses (4 x 3.5 = 14), then hours before driving = units above the legal limit (14 - 3 = 11), at one unit removed per hour.

Before you begin

  • Rearranging equations with three terms.
  • Unit conversions for length, time and volume.
  • Standard form and significant figures.
1

The method

  1. Write the equation and rearrange it so the unknown is the subject.

    Why: The rearranged equation with numbers is often the first mark.

  2. Write each value with its unit and convert any that do not match.

    Why: Unit conversion is a common marking point.

  3. Substitute the numbers and calculate.

    Why: This gives the middle mark.

  4. Convert the answer to the unit asked (minutes, ms, cm3).

    Why: The final mark is for the asked unit.

  5. Round or use standard form as instructed.

    Why: Ignoring the instruction can lose the last mark.

Do not lose marks here

  • ✗
    Multiplying distance by speed when time is wanted.
  • ✗
    Forgetting to change seconds into minutes, giving 2571 instead of 43.
  • ✗
    Changing 5 minutes to 500 seconds instead of 300 seconds.
  • ✗
    Leaving stroke volume in dm3 when cm3 is asked.
  • ✗
    Using the final temperature instead of the temperature rise.
  • ✗
    Forgetting the square root in the reaction-time formula, so 0.15 m gives 0.03 s instead of 0.17 s.

Worked explanation

  1. speed = distance / time, so time = distance / speed.
  2. Distance = 180 mm and speed = 0.070 mm/s. The units match (mm), so the time will be in seconds.
  3. time = 180 / 0.070 = 2571.4 s.
  4. The answer must be in minutes: 2571.4 / 60 = 42.86 minutes.
  5. Round sensibly: 43 minutes.
Model answer · written by olevels.com, not an official Pearson mark scheme

time = distance / speed = 180 / 0.070 = 2571 s. 2571 / 60 = 42.9 = 43 minutes.

How the marks are earned

One mark for dividing 180 by 0.070. One mark for 2571 seconds. One mark for dividing by 60 to give about 43 minutes (any value that rounds to 43). The last mark can follow on from a wrong seconds value if it is divided by 60 correctly.
