Idea. Food contains large molecules. Each large molecule is built from small units joined together, like beads on a string. Digestion breaks them back into small units. An element is a simple substance made of one type of atom. Carbohydrates contain only carbon, hydrogen and oxygen. Lipids, which are fats and oils, also contain only these three. Proteins contain nitrogen too, and some contain sulfur.

Method. Carbohydrates are built from simple sugars. Glucose is a simple sugar, also called a monosaccharide. Starch and glycogen are large carbohydrates. They are made of many glucose molecules joined in chains. A disaccharide is two simple sugars joined together. Lactose, the sugar in milk, is a disaccharide. Starch is not a disaccharide. It has many sugar units joined. Proteins are made of amino acids joined together. Enzymes are proteins too. Lipids are made of glycerol and fatty acids. So the method is: decide which molecule the question is about. For elements, start with carbon, hydrogen and oxygen, and add nitrogen only for protein. For structure, name the small unit, and say the units are joined. In a matching question, draw only one line from each box.

Worked example. Now a real exam question. It says enzymes are protein molecules. Then it asks which sub-units form enzymes. There are four options. One mark. The stem tells us enzymes are proteins. So the question really asks: what are proteins made of? Amino acids. So the answer is A. Check the others. Fatty acids and glycerol build lipids. Glucose builds carbohydrates. So B, C and D are wrong. So the answer is A, amino acids. This reasoning is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is to say lipids contain nitrogen. They do not. Of these three food molecules, only proteins contain nitrogen. Another mistake is to write only that glycogen is made of glucose. Say that many glucose molecules are joined together.

Your turn. Olive oil is a lipid. Name the elements in a lipid. Then name the small units that a lipid is made from. Pause here and work it out.

Answer. First, the elements. A lipid contains carbon, hydrogen and oxygen. There is no nitrogen, because, of these three food molecules, only proteins contain nitrogen. Then the units. A lipid is made of glycerol joined to fatty acids. So, every time: decide which molecule it is. Elements: carbon, hydrogen and oxygen, plus nitrogen for protein. Structure: name the units, and say they are joined.
