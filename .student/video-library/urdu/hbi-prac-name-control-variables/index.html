Idea۔ Variable کوئی بھی factor ہے جو بدل سکتا ہے، جیسے temperature یا volume۔ Investigation میں تین قسمیں ہوتی ہیں۔ Independent variable وہ ہے جو آپ بدلتے ہیں۔ Dependent variable وہ ہے جو آپ measure کرتے ہیں۔ Control variables وہ ہیں جو آپ same رکھتے ہیں۔ انہیں same کیوں رکھیں؟ فرض کریں ایک student temperature بدلتی ہے، لیکن pH بھی بدل جاتا ہے۔ Results بدل جاتے ہیں۔ کس factor نے کیا؟ آپ بتا نہیں سکتے۔ اس لیے صرف independent variable بدل سکتا ہے۔ باقی سب controlled ہے۔

Method۔ Step ایک۔ وہ دو variables ڈھونڈیں جو کبھی controls نہیں ہو سکتے۔ Enzyme ایک protein ہے جو reaction تیز کرتا ہے۔ Amylase وہ enzyme ہے جو starch کو digest کرتا ہے۔ ایک student اسے مختلف temperatures پر test کرتی ہے، اور ناپتی ہے کہ starch کو غائب ہونے میں کتنا وقت لگتا ہے۔ Temperature independent variable ہے۔ Time dependent variable ہے۔ Step دو۔ method کی ہر دوسری quantity کی list بنائیں۔ یہاں ہر solution کی volume اور concentration same رکھیں۔ Concentration کا مطلب ہے پانی میں کتنا حل ہے۔ Step تین۔ وہ factors شامل کریں جو method بھول گیا۔ Enzymes پر pH اثر کرتا ہے، اس لیے pH کو buffer سے same رکھیں، یعنی وہ solution جو pH کو مستحکم رکھتا ہے۔ Temperature بھی عموماً control ہوتا ہے۔ یہاں نہیں، کیونکہ temperature بدلا جا رہا ہے۔ Step چار۔ ہر control کو ایسے factor کے طور پر لکھیں جسے آپ measure کر سکیں، ہر line پر ایک۔ Volume of starch solution لکھیں، amount of starch نہیں۔ کبھی same conditions یا fair test نہ لکھیں۔ یہ کسی factor کا نام نہیں۔ کچھ investigations لوگوں پر ہوتی ہیں، مثلاً exercise سے heart rate کیسے بدلتا ہے۔ Heart rate ایک منٹ میں دھڑکنوں کی تعداد ہے۔ Same age اور sex کے لوگ لیں، یا ہر بار same شخص۔ Exercise کی type اور length same رکھیں، اور test سے پہلے کھانا اور پینا بھی۔

Worked Example۔ اب ایک اصلی exam question۔ ایک student enzyme phosphatase کو inhibitor کے ساتھ study کرتی ہے۔ Inhibitor وہ substance ہے جو enzyme کو آہستہ کرتا ہے۔ Method میں substrate کی چھ concentrations استعمال ہوتی ہیں۔ Substrate وہ substance ہے جس پر enzyme عمل کرتا ہے۔ Question تین variables مانگتا ہے جو constant رکھنے ہیں۔ پہلے وہ دو variables ڈھونڈیں جو answers نہیں ہو سکتے۔ Substrate کی چھ concentrations بنتی ہیں، اس لیے substrate concentration independent variable ہے۔ Pink colour کو colorimeter سے پڑھا جاتا ہے، جو colour ناپنے والی machine ہے۔ یہ dependent variable ہے۔ Volumes method میں پہلے سے fixed ہیں۔ اس لیے سوچیں کہ اور کیا enzyme کی رفتار بدلتا ہے۔ Temperature۔ pH۔ اور enzyme کی concentration۔ Inhibitor کی concentration پر بھی ایک mark ملتا۔ تو جواب تین precise factors ہیں، ہر line پر ایک۔ ایک: temperature۔ دو: pH۔ تین: concentration of the enzyme۔ یہ جواب olevels dot com کا ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی یہ ہے کہ independent variable کو control کے طور پر دے دیا جائے۔ اس question میں substrate concentration جان بوجھ کر بدلی جاتی ہے۔ اس لیے یہ آپ کا answer کبھی نہیں ہو سکتی۔ ایک اور غلطی مبہم الفاظ ہیں۔ Amount اکثر رد کر دیا جاتا ہے، اور same conditions کسی چیز کا نام نہیں۔ Volume یا mass لکھیں، اور factor کا نام بتائیں۔

Your Turn۔ ایک student کھانے کا ٹکڑا پانی کی tube کے نیچے جلاتی ہے۔ وہ ناپتی ہے کہ پانی کا temperature کتنا بڑھتا ہے۔ وہ یہ چار مختلف foods کے لیے کرتی ہے۔ State کریں کہ کون سے تین variables اسے same رکھنے چاہییں۔ رک کر سوچیں۔

Answer۔ Independent variable، food کی type ہے۔ Dependent variable، پانی کے temperature کا rise ہے۔ اس لیے ان میں سے کوئی بھی answer نہیں ہو سکتا۔ اب controls۔ ہر food کے ٹکڑے کی mass same رکھیں۔ پانی کی volume same رکھیں۔ Food اور tube کے درمیان فاصلہ same رکھیں۔ تو ہر بار: independent اور dependent variables کاٹ دیں۔ Method کی باقی quantities کی list بنائیں۔ Temperature یا pH شامل کریں۔ پھر ہر factor کو precisely نام دیں۔
