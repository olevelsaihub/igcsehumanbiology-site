Idea۔ Variable وہ factor ہے جو بدل سکتا ہے۔ ایک student وہی enzyme تین tubes میں ڈالتی ہے۔ Enzyme ایک protein ہے جو reaction تیز کرتا ہے۔ وہ ہر tube کو مختلف temperature پر رکھتی ہے: بیس، چالیس اور ساٹھ degrees Celsius۔ یہ اس نے جان بوجھ کر چنے۔ جو factor آپ جان بوجھ کر بدلیں، وہ independent variable ہے۔ پھر وہ measure کرتی ہے کہ ہر tube کو اپنا food digest کرنے میں کتنا وقت لگتا ہے۔ یہ times اس نے نہیں چنے۔ وہ انہیں پڑھتی ہے۔ جو آپ effect دیکھنے کے لیے measure کریں، وہ dependent variable ہے۔ یہ independent variable پر depend کرتا ہے۔ باقی سب کچھ same رہتا ہے: وہی enzyme، وہی volume، وہی pH۔ pH بتاتا ہے کہ liquid کتنا acidic یا alkaline ہے۔ جو factors same رکھے جاتے ہیں وہ control variables ہیں۔ یہ test کو fair بناتے ہیں۔

Method۔ Results tables آپ کی مدد کرتے ہیں۔ Independent variable عموماً پہلے column میں ہوتا ہے۔ باقی columns میں readings ہوتی ہیں، اس لیے وہ dependent variable دکھاتے ہیں۔ Independent variable ایک type بھی ہو سکتا ہے، number نہیں۔ اس dish میں jelly پر bacteria اگتے ہیں۔ ہر paper disc میں مختلف antibiotic ہے۔ Antibiotic ایک drug ہے جو bacteria کو مارتی ہے۔ جہاں bacteria مرتے ہیں وہاں clear zone بنتا ہے۔ Independent variable، antibiotic کی type ہے۔ Dependent variable، clear zone کا diameter ہے۔ Time بھی independent variable ہو سکتا ہے۔ یہاں ایک tube oxygen gas نکالتی ہے۔ Student ہر دو منٹ بعد volume پڑھتی ہے۔ وہ times اس نے چنے، اس لیے time independent variable ہے۔ Oxygen کی volume dependent variable ہے۔ تو چار steps ہیں۔ وہ ایک factor ڈھونڈیں جو جان بوجھ کر مختلف ہے۔ وہ reading ڈھونڈیں جو ہر بار record ہوتی ہے۔ Table کے columns چیک کریں۔ پھر ہر variable کو اس کے exact نام سے لکھیں۔

Worked Example۔ یہ ایک اصلی exam question ہے۔ ایک student، lipids کو digest کرنے والا enzyme، lipid solution میں ڈالتی ہے۔ Lipids یعنی fats اور oils۔ دس منٹ تک ہر منٹ pH پڑھا جاتا ہے، سینتیس اور اسی degrees Celsius پر۔ Independent اور dependent variable دیں۔ یہ دو marks کا ہے۔ یہ دونوں tables ایک ساتھ ہیں۔ ان کو compare کریں۔ ان میں کیا مختلف ہے؟ صرف temperature: سینتیس یا اسی degrees۔ یہ student نے چنے۔ اس لیے temperature independent variable ہے۔ ہر box میں کیا record ہوا ہے؟ Solution کا pH۔ اس لیے pH dependent variable ہے۔ Time کو بھی independent مانا جاتا ہے، کیونکہ student نے چنا کب پڑھنا ہے۔ یہ یہ جواب olevels dot com کا ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ سب سے عام غلطی یہ ہے کہ انہیں آپس میں بدل دیا جائے۔ pH چنا نہیں گیا تھا۔ وہ measure ہوا، اس لیے وہ independent نہیں ہو سکتا۔ ایک اور غلطی یہ ہے کہ control variable کا نام لکھ دیا جائے۔ یہاں ہر tube سینتیس degrees پر ہے۔ Temperature نہیں بدلتا، اس لیے وہ control ہے۔ Enzyme کی volume جان بوجھ کر بدلی جاتی ہے، اس لیے وہ independent variable ہے۔ آخری غلطی مبہم نام ہے۔ صرف antibiotic، یا صرف bacteria لکھنے پر کچھ نہیں ملتا۔ بالکل بتائیں کہ کیا بدلتا ہے، یا بالکل کیا measure ہوتا ہے۔
