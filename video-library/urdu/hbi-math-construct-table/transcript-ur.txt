Idea۔ Results table آپ کا data ترتیب سے رکھتا ہے۔ Independent variable، جسے آپ نے بدلا، پہلے column میں جاتا ہے۔ جو results آپ نے ناپے، یعنی dependent variable، اگلے column میں۔ ہر heading quantity کا نام اور اس کی unit دیتی ہے، جیسے time in minutes۔ Units صرف heading میں جاتی ہیں۔ نیچے کے cells میں صرف numbers ہوتے ہیں۔

Method۔ Step ایک۔ ruler سے table بنائیں۔ ہر variable کا ایک column، اور ہر value کی ایک row بنائیں۔ List یا graph table نہیں ہے۔ Step دو۔ پہلے column کی heading independent variable اور اس کی unit سے لگائیں: time in minutes۔ اگلے column کی heading result اور اس کی unit سے: heart rate in beats per minute۔ Step تین۔ Independent variable کو کم سے زیادہ کی ترتیب میں رکھیں۔ ہر result اس کے ساتھی کے ساتھ copy کریں۔ ہر column میں decimal places کی تعداد ایک جیسی رکھیں۔ Frequency table گنتی کرتا ہے کہ ہر value کتنی بار آئی۔ Tally بنائیں: ہر value کے لیے ایک لکیر۔ پانچویں لکیر باقی چار کو کاٹتی ہے، اور پانچ کا gate بنتا ہے۔ پھر لکیریں گنیں۔ کچھ سوال table مکمل کرنے کو کہتے ہیں۔ صرف غائب entry بھریں، column کی باقی entries جیسی شکل میں۔ یہاں آخری frequency غائب ہے۔ Tally میں چار لکیریں ہیں، تو چار لکھیں۔ Cell میں unit کی ضرورت نہیں۔

Worked Example۔ یہ ایک real exam question ہے۔ ایک student potato cylinders کو sugar solutions میں ڈالتا ہے۔ Results mass میں percentage change ہیں، جو گڈمڈ ترتیب میں لکھے ہیں۔ Concentration arbitrary units میں ہے، au: اس test کے لیے بنائی گئی units۔ آپ کو table بنانا ہے۔ Student نے sugar concentration بدلی، اس لیے یہ column ایک میں جاتی ہے، اپنی unit، au، کے ساتھ۔ Result mass میں percentage change ہے، per cent میں۔ اب concentrations کو ترتیب سے رکھیں، صفر اعشاریہ صفر صفر سے ایک اعشاریہ پانچ صفر تک۔ پھر ہر result اس کے ساتھی کے ساتھ copy کریں: plus آٹھ، plus چار، minus ایک، minus سات، اور minus دس۔ Units headings میں ہیں، اس لیے cells میں صرف numbers ہیں۔ یہ table olevels dot com کی طرف سے ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی ہر cell میں unit لکھنا ہے۔ اسے ایک بار heading میں لکھیں۔ ایک اور غلطی results کو اسی گڈمڈ ترتیب میں copy کرنا ہے جس میں دیے گئے تھے۔ پہلے independent variable کو کم سے زیادہ ترتیب دیں۔

Your Turn۔ ایک nurse بارہ patients کے blood groups record کرتی ہے: A، O، O، B، A، O، AB، O، A، O، B، O۔ ان results کا frequency table بنائیں۔ یہاں رک کر خود حل کریں۔

Answer۔ Columns کی headings لکھیں: blood group، tally، اور number of patients۔ Groups نام ہیں، numbers نہیں، تو انہیں سب سے زیادہ common سے سب سے کم تک رکھیں۔ ہر ایک کا tally لگائیں: O چھ، A تین، B دو، AB ایک۔ پھر ہر count آخری column میں لکھیں۔ Total check کریں: چھ plus تین plus دو plus ایک، بارہ، یعنی patients کی تعداد۔ تو ہر بار: table ruler سے بنائیں۔ Independent variable پہلے رکھیں، اس کی unit heading میں۔ Values ترتیب سے رکھیں۔ ہر result اس کے ساتھی کے ساتھ copy کریں۔
