Idea۔ Vaccine میں pathogen کے antigens ہوتے ہیں۔ Pathogen ایک microorganism ہے جو بیماری کرتا ہے، اور antigen اس کی سطح پر ایک protein ہے۔ Vaccine میں مردہ یا کمزور pathogen ہو سکتا ہے، یا صرف اس کے antigens۔ یہ آپ کو بیمار نہیں کر سکتی۔ Lymphocytes، white blood cell کی ایک قسم، antigens کو detect کرتے ہیں۔ وہ ان antigens میں فٹ ہونے والے antibodies بناتے ہیں۔ کچھ lymphocytes memory cells بن جاتے ہیں، جو جسم میں سالوں رہتے ہیں۔ Active immunity کا مطلب ہے کہ آپ کا اپنا جسم antibodies بناتا ہے۔ بیماری خود لگنے سے بھی یہی ہوتا ہے: یہ natural active immunity ہے۔

Method۔ یہ vaccine کے بعد antibody level ہے۔ پہلا response آہستہ اور چھوٹا ہوتا ہے۔ مگر memory cells بنتے ہیں، اور رہتے ہیں۔ بعد میں اصل pathogen داخل ہوتا ہے۔ اب memory cells بہت تیزی سے بہت زیادہ antibodies بناتے ہیں۔ Symptoms شروع ہونے سے پہلے level لائن سے اوپر چلا جاتا ہے۔ تو pathogen ختم ہو جاتا ہے اور شخص بیمار نہیں ہوتا۔ Antibody levels وقت کے ساتھ گرتے ہیں۔ یہاں وہ safe level سے نیچے آ جاتے ہیں۔ Vaccine کی booster dose انہیں دوبارہ بڑھاتی ہے، اور مزید memory cells بناتی ہے۔ جب زیادہ تر لوگوں کو vaccine لگ جائے تو pathogen کو لگانے اور پھیلانے والے لوگ کم ہوتے ہیں۔ تو یہ کم پھیلتا ہے۔ جنہیں vaccine نہیں لگی وہ بھی محفوظ ہو جاتے ہیں۔ یہ herd immunity ہے۔

Worked Example۔ یہ ایک اصلی exam question ہے۔ Explain کریں کہ vaccination کسی شخص کو بیماری سے immunity کیسے دے سکتی ہے۔ پانچ marks۔ Step ایک: pathogen کی مردہ یا کمزور شکل inject کی جاتی ہے۔ اس میں antigens ہوتے ہیں۔ Step دو: lymphocytes antigens کو detect کرتے ہیں اور antibodies بناتے ہیں۔ Step تین: کچھ antibodies کچھ دیر blood میں رہتے ہیں۔ Step چار: memory cells بنتے ہیں، اور جسم میں رہتے ہیں۔ Step پانچ: اصل pathogen داخل ہو تو memory cells جلدی بہت سے antibodies بناتے ہیں، اس لیے شخص بیمار نہیں ہوتا۔ جواب olevels dot com کا ہے، یہ official mark scheme نہیں ہے۔ تو پورے جواب میں پانچ جڑے ہوئے steps ہیں، order میں، injection سے تیز response تک۔

Common Mistake۔ ایک عام غلطی یہ کہنا ہے کہ vaccine میں antibodies ہوتے ہیں۔ اس میں antigens ہوتے ہیں۔ Antibodies آپ کے اپنے lymphocytes بناتے ہیں۔ ایک اور غلطی یہ لکھنا ہے کہ جسم بیماری کو یاد رکھتا ہے۔ Memory cells کا نام لیں، اور لکھیں کہ اگلی بار وہ antibodies زیادہ تیزی سے بناتے ہیں۔

Your Turn۔ Leena کو پانچ سال کی عمر میں chickenpox ہوا، اور وہ بیمار ہوئی۔ بیس سال کی عمر میں اس کا دوبارہ chickenpox virus سے سامنا ہوتا ہے، مگر وہ بیمار نہیں ہوتی۔ Explain کریں کیوں۔ رک کر خود حل کریں۔

Answer۔ پانچ سال کی عمر میں اس کے lymphocytes نے virus کے antigens کو detect کیا اور antibodies بنائے۔ یہ آہستہ تھا، اس لیے وہ بیمار ہوئی۔ مگر memory cells بنے، اور رہے۔ بیس سال کی عمر میں اس کے memory cells نے antigens کو پہچانا۔ انہوں نے بہت تیزی سے بہت زیادہ antibodies بنائے۔ Symptoms شروع ہونے سے پہلے virus ختم ہو گیا۔ تو ہر بار: antigens اندر آئے، lymphocytes antibodies بناتے ہیں، memory cells رہتے ہیں، اور اگلا response تیز اور بڑا ہوتا ہے۔
