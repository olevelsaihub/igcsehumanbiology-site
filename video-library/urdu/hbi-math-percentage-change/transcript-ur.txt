Idea۔ Percentage change، change کا starting value سے موازنہ کرتا ہے۔ ایک بچے کی mass چار اعشاریہ صفر سے پانچ اعشاریہ صفر kilograms ہو جاتی ہے۔ اس میں ایک اعشاریہ صفر kilogram کا اضافہ ہوا۔ start کے حصے کے طور پر یہ چار اعشاریہ صفر میں سے ایک اعشاریہ صفر ہے، یعنی پچیس per cent۔

Method۔ Rule یہ ہے۔ new value میں سے original value subtract کریں۔ original value سے divide کریں۔ پھر سو سے multiply کریں۔ Original value ہمیشہ نیچے آتی ہے۔ Step ایک۔ دونوں values units کے ساتھ ڈھونڈیں۔ Step دو۔ طے کریں کہ original کون سی ہے۔ یہ starting value ہے، یا وہ جو لفظ compared with کے بعد آئے۔ Percentage difference بھی ایسے ہی کام کرتا ہے: compared with کے بعد والی value نیچے جاتی ہے۔ Step تین۔ Subtract کریں: new minus original۔ Positive answer کا مطلب increase ہے۔ Negative answer کا مطلب decrease۔ Step چار۔ change کو original سے divide کریں، اور سو سے multiply کریں۔ Step پانچ۔ جیسے question کہے round کریں۔ تب تک تمام digits رکھیں۔ per cent کا sign لگائیں، اور بتائیں increase یا decrease۔ Minus sign fall دکھاتا ہے۔ دونوں values ایک ہی units میں ہوں۔ چھ سو پچاس ہزار، صفر اعشاریہ چھ پانچ million ہے۔ تو ایک اعشاریہ چار million minus صفر اعشاریہ چھ پانچ million، صفر اعشاریہ سات پانچ million۔ صفر اعشاریہ چھ پانچ سے divide کریں اور سو سے multiply: ایک سو پندرہ per cent۔ Increase سو per cent سے زیادہ بھی ہو سکتا ہے۔

Worked Example۔ یہ ایک real exam question ہے۔ دو ہزار میں سات اعشاریہ صفر million لوگ heart disease سے مرے۔ ایک bar chart میں دو ہزار سولہ کی deaths ہیں۔ دو ہزار سے دو ہزار سولہ تک percentage change calculate کریں۔ دو ہزار پہلے آتا ہے، تو سات اعشاریہ صفر million original value ہے۔ اب دو ہزار سولہ کا bar پڑھیں۔ heart disease کا bar نو اور دس کے بالکل بیچ میں ختم ہوتا ہے۔ تو new value نو اعشاریہ پانچ million ہے۔ Subtract کریں: نو اعشاریہ پانچ minus سات اعشاریہ صفر، دو اعشاریہ پانچ million۔ یہ positive ہے، تو deaths بڑھ گئیں۔ Original سے divide کریں: دو اعشاریہ پانچ تقسیم سات اعشاریہ صفر، ضرب سو، پینتیس اعشاریہ سات۔ whole number تک یہ چھتیس per cent increase ہے۔ یہ working olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ سب سے عام غلطی غلط value سے divide کرنا ہے۔ دو اعشاریہ پانچ تقسیم نو اعشاریہ پانچ سے چھبیس per cent آتا ہے۔ یہ غلط ہے، کیونکہ نو اعشاریہ پانچ new value ہے، original نہیں۔ ایک اور غلطی new value کو old کے percentage کے طور پر لکھنا ہے۔ سات اعشاریہ صفر میں سے نو اعشاریہ پانچ، ایک سو چھتیس per cent ہے۔ یہ change نہیں ہے۔ نیز، بہت جلدی round نہ کریں، اور fall کے لیے minus sign نہ بھولیں۔
