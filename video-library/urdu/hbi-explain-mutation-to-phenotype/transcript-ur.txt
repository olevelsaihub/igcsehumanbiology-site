Idea۔ آپ کے genes، DNA سے بنے ہیں۔ Gene، DNA کا ایک چھوٹا حصہ ہے جو ایک protein کا code رکھتا ہے۔ Code، bases کی لمبی قطار ہے: DNA کے چار حروف A، T، C اور G۔ ہر تین bases، جنہیں triplet یا codon کہتے ہیں، ایک amino acid کا code ہیں۔ Amino acids وہ چھوٹی units ہیں جو جڑ کر protein بناتی ہیں۔ Amino acids کی chain مڑ کر اپنی ایک shape والا protein بن جاتی ہے۔ یہی shape اسے اپنا کام کرنے دیتی ہے۔ Proteins آپ کی خصوصیات بناتے ہیں۔ آپ کا phenotype وہ ہے جو آپ ہیں: آپ کی تمام characteristics۔

Method۔ Step ایک۔ Mutation، gene کی base sequence میں تبدیلی ہے۔ یہاں ایک base بدل گیا ہے۔ Step دو۔ اس لیے وہ triplet بدل جاتا ہے۔ اب وہ کسی دوسرے amino acid کا code ہو سکتا ہے۔ یا وہ stop signal بن سکتا ہے، اس لیے protein بنتا ہی نہیں۔ Step تین۔ Amino acids مختلف ترتیب میں ہیں، اس لیے protein مختلف shape میں مڑتا ہے۔ ہو سکتا ہے وہ کام نہ کرے۔ Enzyme وہ protein ہے جو reaction کو تیز کرتا ہے۔ اس کی active site وہ حصہ ہے جس میں اس کا substrate fit ہوتا ہے، یعنی وہ molecule جس پر وہ کام کرتا ہے۔ Mutation کے بعد active site شاید اپنے substrate میں fit نہ ہو۔ Step چار۔ خراب یا غائب protein ایک characteristic بدل دیتا ہے۔ یہ phenotype میں تبدیلی ہے۔ Sickle cell anaemia میں ایک base کی تبدیلی سے خراب haemoglobin بنتا ہے، وہ protein جو oxygen لے جاتا ہے۔ Red blood cells درانتی کی طرح مڑ جاتے ہیں۔

Worked Example۔ یہ ایک real exam question ہے۔ Polycystic kidney disease کے مریضوں کے kidneys پر cysts ہوتے ہیں۔ Cysts، fluid کی تھیلیاں ہیں۔ یہ بیماری gene mutation سے ہوتی ہے۔ Explain کریں کہ gene mutation، phenotype پر کیسے اثر ڈال سکتی ہے۔ تین marks۔ DNA سے شروع کریں۔ Link ایک، gene کی base sequence بدل جاتی ہے۔ Link دو، اس لیے amino acids کی مختلف ترتیب کا code بنتا ہے۔ Link تین، protein کی shape مختلف ہے، اس لیے وہ کام نہیں کرتا۔ Link چار، ایک characteristic بدل جاتی ہے۔ یہاں kidneys میں cysts بنتے ہیں۔ یہ مکمل answer ہے: تین marks کے لیے چار links۔ یہ جواب olevels dot com کا ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی یہ ہے کہ DNA سے سیدھا بیماری پر چھلانگ لگا دی جاتی ہے۔ آپ درمیان کے marks کھو دیتے ہیں۔ ہمیشہ amino acids اور protein سے گزریں۔ ایک اور غلطی یہ کہنا ہے کہ ہر mutation، phenotype بدلتی ہے۔ کچھ mutations کا کوئی اثر نہیں ہوتا۔ نیا triplet اسی amino acid کا code ہو سکتا ہے، یا protein پھر بھی کام کر سکتا ہے۔

Your Turn۔ Melanin جلد اور بالوں کا گہرا رنگ ہے۔ ایک enzyme اسے بناتا ہے۔ اس enzyme کے gene میں mutation سے albinism ہوتا ہے: بہت ہلکی جلد اور بال۔ Explain کریں کہ کیسے۔ یہاں رک کر سوچیں۔

Answer۔ Mutation، enzyme کے gene کی base sequence بدل دیتی ہے۔ اس لیے amino acids کی مختلف ترتیب کا code بنتا ہے۔ Enzyme مختلف shape میں مڑتا ہے۔ اس کی active site اب اپنے substrate میں fit نہیں ہوتی۔ اس لیے enzyme، melanin نہیں بنا سکتا۔ Melanin کے بغیر جلد اور بال بہت ہلکے ہوتے ہیں۔ یہ phenotype میں تبدیلی ہے: albinism۔ تو ہر بار: bases، پھر amino acids، پھر protein، پھر phenotype۔ ہر link کو so سے جوڑیں۔
