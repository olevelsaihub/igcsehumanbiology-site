Plot a line graph from a table of results

Idea. A line graph shows how one quantity changes as another changes smoothly, like time. Time is continuous: every value in between is possible. In this made-up example, oxygen is given off by an enzyme, and its volume is measured every 2 minutes. An enzyme is a protein that speeds up a reaction.

Method. Step one. The x-axis is the line across the bottom. The y-axis is the line up the side. Put the variable you changed on the x-axis. That is usually time. The variable you measured goes on the y-axis. Copy each axis label, with its unit, from the table heading. Step two. Choose a scale with equal, easy steps, like 1, 2, 5, 10 or 20 for each big square. For minutes, 15 also works. The points must fill more than half the grid each way. Step three. Plot each point with a small, neat cross, using a sharp pencil. Each point must be accurate to half a small square. Step four. Join the points exactly as the question says. Some questions want straight lines, drawn with a ruler from point to point. Others want one smooth curve. If it says neither, only plot the points. With two sets of data, plot both on the same grid. Then label each line, or add a key, so the examiner knows which is which.

Worked example. Here is a real exam question. A glucose tolerance test measures blood glucose every 30 minutes for 3 hours, for a person without diabetes and a person with diabetes. Plot the results, and join the points with straight lines. Here is the table of results. Time in minutes is in the first column. Then the blood glucose in milligrams per 100 cubic centimetres, for the person without diabetes and the person with diabetes. Time was chosen by the scientist, so it goes on the x-axis. The grid is 16 big squares wide. 15 minutes per big square uses 12 of them. Glucose goes up to 230, so 0 to 240, in 20s, uses all 12 big squares up. Plot the seven points for each person. Without diabetes: 65, 120, 130, 95, 80, 65 and 65. With diabetes: 110, 215, 230, 200, 190, 180 and 170. Join each set with straight lines, using a ruler. Then label the lines: without diabetes, and with diabetes. This graph is by olevels.com, not an official mark scheme.

Common mistake. A common mistake is putting time on the y-axis. Time was chosen, so it always goes across, on the x-axis. Another mistake is an uneven scale, or a scale that uses less than half the grid. Use equal steps, and spread the points out.

Your turn. After exercise, a student's pulse rate is measured every 2 minutes for 10 minutes: 120, 105, 92, 84, 78 and 76 beats per minute. Plot a graph and join the points with a smooth curve. Pause here and work it out.

Answer. Time goes on the x-axis, from 0 to 10, in steps of 2. Pulse rate goes on the y-axis, from 0 to 140, in steps of 20. Label both axes with their units. Plot the six points with neat crosses. Then draw one smooth curve through them, without a ruler. So, every time: the changed variable on the x-axis. Label both axes with units. Use an even scale over half the grid. Plot carefully, then join as the question says.
