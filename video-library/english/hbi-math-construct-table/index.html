Idea. A results table puts your data in order. The independent variable, the one you changed, goes in the first column. The results you measured, the dependent variable, go in the next column. Each heading names the quantity and gives its unit, like time in minutes. The units go in the heading only. The cells below hold just the numbers.

Method. Step one. Rule a table with a ruler. Draw one column for each variable, and one row for each value. A list or a graph is not a table. Step two. Head the first column with the independent variable and its unit: time in minutes. Head the next column with the result and its unit: heart rate in beats per minute. Step three. Put the independent variable in order, from lowest to highest. Copy each result next to its partner. Keep the same number of decimal places in each column. A frequency table counts how many times each value appears. Make a tally: one stroke for each value. The fifth stroke crosses the other four, making a gate of five. Then count the strokes. Some questions ask you to complete a table. Fill in only the missing entry, in the same form as the rest of the column. Here the last frequency is missing. The tally has four strokes, so write 4. No unit is needed in the cell.

Worked example. Here is a real exam question. A student puts potato cylinders into sugar solutions. The results are the percentage change in mass, written in a jumbled order. Concentration is in arbitrary units, au: units made up for this test. You must draw a table. The student changed the sugar concentration, so it goes in column one, with its unit, au. The result is the percentage change in mass, in per cent. Now put the concentrations in order, from 0.00 to 1.50. Then copy each result next to its partner: plus 8, plus 4, minus 1, minus 7, and minus 10. The units are in the headings, so the cells hold only numbers. Common mistake. A common mistake is writing the unit in every cell. Put it once, in the heading. Another mistake is copying the results in the jumbled order they were given. Order the independent variable first, from lowest to highest.

Your turn. A nurse records the blood groups of 12 patients: A, O, O, B, A, O, AB, O, A, O, B, O. Draw a frequency table of these results. Pause here and work it out.

Answer. Head the columns: blood group, tally, and number of patients. Groups are names, not numbers, so put them from the most common to the least. Tally each one: O has six, A has three, B has two, AB has one. Then write each count in the last column. Check the total: 6 plus 3 plus 2 plus 1 is 12, the number of patients. So, every time: rule the table. Put the independent variable first, with its unit in the heading. Put the values in order. Copy each result next to its partner.
